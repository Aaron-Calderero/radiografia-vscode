Visual Studio Code

Un editor de código gratuito, ligero y ampliable con extensiones.

¿Por qué se usa tanto?

Combina un editor rápido con depurador, terminal integrada y control de Git, todo en una sola ventana. Funciona en Windows, macOS y Linux.

Atajos imprescindibles

AtajoAcción
Ctrl + PAbrir un archivo por nombre
Ctrl + Shift + PPaleta de comandos
en ubuntu: Ctrl + `Mostrar u ocultar la terminal
en windows: Ctrl + ñMostrar u ocultar la terminal

Aún no has pulsado el botón.

Más información

Instalación

Se descarga gratis desde la web oficial. En Linux también está disponible como paquete .deb, .rpm o Snap.

Ventajas

Es rápido, tiene una enorme comunidad y su Marketplace ofrece miles de extensiones para casi cualquier lenguaje.

Extensiones recomendadas

Live Server para servir la página en local, ESLint para detectar errores y Prettier para formatear el código.
